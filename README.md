# 學生模擬器 — 遊戲開發交接文件

> 最後更新：2026-10-26（指導書另見 `學生模擬器指導書.md`）  
> 用途：方便下一輪對話快速接手開發、除錯與擴充

## 1. 專案概要

- **作品名稱**：學生模擬器（畫面標題固定；女主角／男朋友名稱可自訂）
- **類型**：NTR／露出／公共調教向文字遊戲
- **技術**：單一 `.html` 檔，純前端（localStorage 存檔）
- **核心循環**：早晨選穿搭與配件 → 日間地點／上課／打工／體育課 → 回家（精液反應／洗澡）→ 晚間（夜遊／上床／洗澡／結束）→ 隔天
- **時間**：白天 8 小時、晚上 4 小時。一般事件半小時，約會 1 小時。時間用完必須回家。

## 2. 角色與關係設定

| 角色 | 預設名 | 說明 |
|------|--------|------|
| 女主角 | 千紗 | 玩家控制，可自訂名稱 |
| 男朋友 | 山本 | 可自訂名稱；依知情度／屈服度／好感度改變態度 |

### 男朋友行為分層（知情度 know）

| 區間 | 行為 |
|------|------|
| ≤30 | 幾乎無 NTR 互動；≥20 時會有心中 OS |
| 30 < know ≤60 | 會懷疑、可能跟蹤（顯示機率）；被跟蹤發現 +知情度 |
| 60 < know ≤90 | 對話明示發現出軌／被使用，憤怒與不解 |
| >90 | 更接近接受／參與；屈服度高時會主動安排 |

### 屈服度（yield, 0–200）

- **<100**：不會出現「男朋友主動安排夜間使用」
- **≥100**：可能出現主動安排
- 與男朋友約會條件：**知情度 <70 且屈服度 <70**，每天一次。約會降低知情度與屈服度，並提高好感度

### 好感度（affection, 0–100，預設 50）

- 與男朋友約會：+12
- 男友目擊性愛事件：−14
- 晚間「跟男友上床」依好感／知情／屈服分差分（見第 10 節）

### 沉淪度（corruption, 0–100）

- 開局預設 **0**
- 影響接受選項門檻、敘事語氣
- **忍受體力**：基礎被操 10／騷擾 5，實際扣除 = `基礎 × (1 − 沉淪/50)`；沉淪 ≥50 時扣除 = 0
- **欣然接受**：改為回體力，至少 +4，並隨沉淪上升（沉淪 50 約 +8，100 約 +12）。日間上限 100，夜遊上限 30

## 6. 地點系統

### 校內（CAMPUS_LOCS）

自己的教室、美術教室、屋頂、女廁、空教室、體育館器材室、老師辦公室、操場

### 校外（OUT_LOCS）

便利商店巷弄、河岸、舊公寓、停車場、公共浴場、公園

### 移動

- 校外：地鐵 or 他人的車（需沉淪 ≥50 且知名度 ≥50）
- 地鐵途中可觸發騷擾／被操（拍攝機率更高）
- **列車事件結束後必須抵達目的地**（`arrive_dest`），再觸發該地點事件

### 事件地點人數（LOC_PEOPLE）

依地點亂數，例如：教室 6–20、便利商店 1–5、空教室 1–2、河岸 5–10、電車 8–25。

用途：知名度上升 `fameGain ≈ base × (1 + 人數/5)`、露出經驗、露出「發現人數」上限。

### 進入地點判定順序（非電車）

1. **偶遇具名 NPC**（約 75%，優先）
2. 裸露騷擾加成（僅該地第一次；上空／下空 +20%，全裸 +40%）
3. 知名度事件（多人被操／單人被操／騷擾／偷窺）
4. 無事件 → `stay_loc`

### 事件後流程

事件結束後 → **留在原地**（`stay_loc`）：

1. 進行日常活動
2. 什麼都不做，休息
3. 野外露出（條件符合時）
4. 穿回已脫衣物（依目前狀態）
5. 離開此地，前往其他地方（才進 `after_loc`）
6. 直接回家

不要一結束事件就強制跳回地點選擇。

| 知名度 | 主要事件 |
|--------|----------|
| <10 | 偷窺／偷拍為主 |
| 10–30 | 騷擾為主 |

| ≥80 | 多人比重提高；有機率觸發「亂交日」 |

配件會提高對應機率。拍攝／上傳：一般約 70%，電車約 90%。

## 8. 多段事件（騷擾／被操）

選項：

- **反抗**：扣較多體力（被操 14／騷擾 9）；成功機率騷擾 50%／被操 30%；成功則中斷
- **忍受**：耗體隨沉淪下降，沉淪 ≥50 時為 0；沉淪與興奮上升，事件繼續
- **欣然接受**：需沉淪或興奮 ≥50；回體力（見第 2 節）；數值上升更多，事件繼續

事件依 `shotsLeft` 與強度推進，直到對方「滿意」（射精次數概念）。  
結束時有嘲弄、射在哪裡等收尾；沉淪 >50 時事後描寫偏「回味／餘韻」。

### 騷擾連續行為鏈

- `HARASS_CHAIN`：每個動作有 text 與 next
- 例：嘴邊摩擦 → 強迫口交；摩擦陰蒂 → 手指插入前穴
- 每階段依上一 actionKey 的 next 隨機選取

### 多人動態體位

- 每位參與者每階段獨立 50% 機率決定是否插入（至少保留 1 人）
- 部位池：口、胸、穴、後穴、左手、右手（等機率、不重複）
- 依部位過濾體位：躺下／趴下／站立／跪姿／坐著上位
- 有「口」排除站立；口+穴+後穴同時排除坐著上位；雙穴+多人排除站立
- 文本依人數、部位、體位、強度、沉淪度動態產生

### 流程

- 好感 <20 且衝動 >50：騷擾 `(衝動/2)%`、被操 `(衝動/3)%`。文本依身分差分。襲擊降好感、升衝動經驗，結束後回原地選單。

## 10. 回家與晚間

### 回家對話

原本依知情／屈服的對話仍在，並追加精液反應：

- <10：沒特別在意
- 10–29：聞到味道，視線停得比較久
- 30–59：看見白濁紋路，問「這是什麼」

## 10b. 上課（自己的教室／美術教室）

stay_loc 多「上課」。共 8 節，每節結束回到下一節選擇；8 節完或提前下課回原地。子事件耗體較低，沉淪越高越低（約 `3 × (1 − 沉淪/80)`，沉淪 ≥80 為 0）。

| 條件 | 選項／結果 |
|------|------------|
| 知名度、沉淪、露出均 <20 | 只有乖乖上課，無事 |
| 20≤知名度<50 | 乖乖上課有機率座位偷摸 |
| 知名度 >50 | 乖乖上課 → 最後一排上課侵犯；沉淪 ≥50 文本偏享受，並有機率多人 |
| 露出 ≥20 | 多「上課露出」：可脫衣改即時狀態，文本強調老師授課時在底下露出 |
| 露出 >40 | 再多「裸體展示課程」「誘惑鄰桌」 |
| 誘惑鄰桌且沉淪 >50 | 下一節多「在教室坐／去走廊做／去男廁所做」 |

| 誘惑鄰桌且沉淪 >50 | 誘惑結束後立刻可選「在教室做／去走廊做／去男廁所做」，之後的節次也保留 |
| 上課露出・自慰 | 指交／拳交／道具都會過半小時並判定被老師發現；被發現 → 公開處罰、打屁股、講台插入 |

裸體展示：教室以生物課人體為由，美術教室以人體素描為由，老師當著學生觸碰。誘惑鄰桌：1～3 人等機率。自慰是兩段式之前的選擇，不是直接結束。

### 操場・體育課

stay_loc 在操場多「上體育課」。四節：熱身、跑步、球類、收操。日常行為是慢跑。露出 ≥20 可「體育課露出」：退到操場邊緣，前面的人還在運動，可脫衣與自慰。自慰與「以目前狀態露出」同級：過時間，並判定被發現。

- 被同學發現：在圍網邊使用
- 被老師發現：脫光後在大家運動時全裸跑步或打球，最後全班圍過來使用

### 便利商店打工

stay_loc 在便利商店多「打工」。共 5 個時段（開店／午前／午休／傍晚／收店），耗體規則同上課。

| 條件 | 選項／結果 |
|------|------------|
| 知名度、沉淪、露出均 <20 | 只有乖乖工作，無事 |
| 20≤知名度<50 | 乖乖工作有機率被同事或客人偷摸 |
| 知名度 >50 | 乖乖工作有機率在櫃檯或倉庫被侵犯；櫃檯文本強調被客人視姦；沉淪 ≥50 偏享受，並有機率多人 |
| 露出 ≥20 | 多「上班露出」：制服圍裙在外，櫃檯下可脫衣改即時狀態 |
| 露出 >40 | 再多「裸體幫客人結帳」「誘惑客人」（櫃檯底下舔陰或指姦） |
| 誘惑客人且沉淪 >50 | 誘惑結束後立刻可選「在櫃檯做／去貨架做／去倉庫做」，之後的時段也保留 |
| 上班露出・自慰 | 指交／拳交／道具都會過半小時並判定被發現；被發現 → 櫃檯被插入，還得報價 |

公共浴場日常是洗澡，清空精液。公園日常是散步。

## 11. 露出系統

### 解鎖

| 露出經驗 | 可選時機 |
|----------|----------|
| ≥20 | 夜遊可選「野外露出」 |
| ≥50 | 白天校外可選 |
| ≥70 | 白天校內也可選 |

### 即時衣著（S.clothes）

- 欄位：top / bottom / bra / panty（true=穿著）
- 早晨依「不穿內衣／內褲」初始化
- 露出脫衣寫入 S.clothes，持續到主動穿回
- stay_loc 依已脫衣物顯示穿回選項
- 結束露出不再強制穿回
- `getClothesAtmosphere()` 在詢問「要做什麼／要去哪裡」的選單顯示氛圍（全裸／上空／下空）

### 流程

1. 脫衣（文本依是否穿內衣／內褲分支）
2. 露出行為：待在原地（+1）／遊蕩（+1.5）／自慰（+2）／結束（維持衣著）
3. 每次行動：被發現值增加（被抓正著機率 ≈ 被發現值 × 20%）；有機率增加發現人數（不超過當地人數）
4. 被抓正著 → 圍觀／羞辱 → 轉入騷擾或被操

發現人數依露出經驗分層：低→羞恥；中→羞恥+微興奮；高→偏興奮。

### 裸露騷擾

進入新地點時，上空或下空 +20%、全裸 +40%，僅該地第一次判定。觸發後約 50% 騷擾向、50% 被操向，文本強調裸露狀態。

## 12. 其他系統

- **高潮**：興奮度 ≥50；沉淪↑、體力↓、興奮歸 0；回到觸發前脈絡
- **亂交日**：高知名度有機率；選項鎖定「繼續當肉便器」直到體力歸零
- **男友目擊**：依知情度機率；專用視窗寫想法與後續；提高知情度與屈服度，性愛目擊降低好感
- **日常活動**：校外需具體，非空泛「日常活動」
- **體位合理性**：三穴需合理姿勢；單穴不限

## 14b. 時間、星期、金錢、德行

- `spendTime(0.5)` 為預設。約會 1 小時。
- 白天 8 小時、晚上 4 小時。用完必須回家。
- 星期：週一到週五。`S.day` 超過 4 進結局。
- 金錢開局 0，顯示在現在狀態。

### 校園德行

- 開局 50。一天上滿 8 節 +5；3 節以上不扣；少於 3 節 −5。上課與體育課都計入 `classCount`。
- 白天第一次進校園判定：
  - 週一、德行 >70：優良學生 +100。>90 再上台領獎 +500。知名度與沉淪均 ≥70 時改成全校亂交獎勵。
  - 週二、10<德行<30：教師約談，耗掉剩餘白天，辦公室一對一調教。
  - 週二、德行 <10：嚴肅教育，所有老師一起教育並使用。

### 心聲

- `voiceHtml()` 優先看當前 passage，再看動作、地點、衣着、配件。
- 進入選單會清掉上一事件的 mood，避免心聲黏住。
- 高潮、多人、被老師／同學發現要用激烈狀聲詞。句號改成點點點。
- 男友目擊頁有「會不會被發現」的心聲，不再掉成地點預設句。

### 胸部大小

- 開局選小／適中／大，存在 `S.bust`。
- `withBust()` 在顯示時把乳尖、乳房、胸部、奶子換成對應寫法，並標【胸部使用】。
- 有實際玩弄的事件會再接 `bustPlay()` 加長描述。男友自己的「胸口堵住」不替換。

## 15. 除錯檢查清單

1. 事件結束後 → stay_loc，不是直接 after_loc
2. 地鐵事件結束 → arrive_dest，再觸發目的地事件
3. 校外事件後的「離開此地」才依 lastArea 給校外優先選項
4. 早晨：興奮度 0、體力 70、配件與衣著重置；精液不清空
5. 發現人數 ≤ 當地人數
6. 露出解鎖門檻依經驗與時段／區域
7. 約會條件是知情與屈服均 <70，不是知名度／屈服 ≥50
8. 進入地點先偶遇，再騷擾／被操
9. 正常 NPC 約會不觸發騷擾／被操
10. 沉淪 ≥50 時忍受不扣體力；接受回體力
11. 洗澡清空精液並回到晚間選單
12. 進校園依賴 `allLocationsDone`，不可刪
13. 誘惑鄰桌／客人後，沉淪 >50 要立刻出現地點選項
14. 上課、上班、體育課的自慰要過時間並判定被發現
15. 心聲要跟當前動作，不要停在上一事件
16. 胸部大小要反映在所有胸部文本，並標【胸部使用】
